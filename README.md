# Research Portfolio

Personal UX/HCI research portfolio intended for static deployment on GitHub Pages.

## Planned stack
- Vite
- HTML
- CSS
- Vanilla JavaScript
- GitHub Pages

React and TypeScript are intentionally excluded from the initial implementation unless a later requirement justifies them.

## Current status
The project is in the planning and design-system stage. Page HTML and the Vite scaffold should be added after the site structure, content model, and visual system are sufficiently defined.

## Project documentation
- `AGENTS.md` — persistent instructions for coding agents.
- `docs/DESIGN_SYSTEM.md` — visual and interaction system.
- `docs/CONTENT_GUIDE.md` — case-study and writing structure.
- `docs/SITE_STRUCTURE.md` — sitemap, page types, navigation, and URL decisions.
- `docs/DEVELOPMENT_NOTES.md` — open questions, implementation notes, and decisions to revisit.

## Development
Development commands will be added after Vite is initialized.

## Deployment
The site will be configured for GitHub Pages after the initial implementation is stable. The final deployment should build static files and publish the generated output through GitHub Actions.
